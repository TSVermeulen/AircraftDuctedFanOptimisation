# Data used in ASME publications of the UDCv2

This dataset contains the data used to create the Turbo Expo 2026 publication GT2026-175354 "A Medium-Fidelity Modelling Framework for Ducted E-Fan Design", and the identically named ASME Journal of Engineering for Gas Turbines and Power paper GTP-26-1236.

The data consists of the validation data against the Bell X-22A, the optimisation configuration files for the framework (config.py), the performance analysis code, and results for the multi-point optimised Bell X-22A design obtained within the abovementioned papers. The performance analysis code performs a parameter sweep of the rotational rate and tip set angle at a given operating condition to create curves of the propulsor efficiency as function of the thrust coefficient for different tip set angles.

The optimisation result objects, stored as .dill files, are not included in this repository due to their size. Instead, they are available from the dataset on the 4TU database [here](https://doi.org/10.4121/02e861af-4062-49ac-a481-32f9e4659b14). These optimisation objects contain both the optimization history and the final optimized population of designs. To load the objects and analyse them in Python, the dill package must be installed together with a copy of the UDC. See also the requirements for the UDC in the parent directory of the UDC codebase. The objects can be loaded using the PostProcessing class of the UDC, part of the GA folder of the UDC. Note that the single- and multi- point optimizations have different configuration files, which must be used appropriately to ensure correct processing of the results objects.
