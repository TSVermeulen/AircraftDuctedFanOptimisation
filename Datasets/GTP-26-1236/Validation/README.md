# Validation data of the UDC against the Bell X-22A

This folder contains all files and data used to perform the validation of the UDC against DFDC and experimental wind tunnel data of the X-22A ducted propeller.

Two spreadsheets are contained in this folder, being:

- Validation Data: The wind tunnel data taken from NASA-TN-D-4142, together with the output data obtained from the UDC for the two blade tip angles considered.
- X22A Propeller Design Data: The chord, geometric, and collective blade angle distributions for the X-22A blade.

Additionally, the blade profiles used to evaluate the UDC in validation are contained in the X22A Blade Profiles subfolder.
